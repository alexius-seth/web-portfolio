# Alexius Seth — Systems & Software Engineer Portfolio

A modern, high-performance developer portfolio built with **Next.js (App Router)**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**, styled with a **Neo-Noir Tech Brutalism** design system.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) 15 (App Router)
- **Library**: [React](https://react.dev/) 19
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Fonts**: Space Grotesk & JetBrains Mono

---

## 🚀 Key Highlights

- **Neo-Noir Tech Brutalism Theme**: Pitch obsidian background (`#07090E`), dark slate surfaces (`#0F141C`), subtle structural borders (`#1E293B`), and neon emerald indicator accents (`#10B981`).
- **Telemetry Hero Section**: Live kinetic radar pulse indicator (`STATUS: OPERATIONAL`), responsive circular profile asset, and quick runtime badge stack.
- **Featured Projects Grid**: Detailed architectural breakdowns, repository source links, live deployment URLs, and single-pass laser scanline hover effects for:
  - **AI-CAMS** (AI-Assisted Assessment Monitoring System)
  - **Talaan** (Local-First Double-Entry Ledger PWA)
  - **CaseKo** (Supreme Court Case Digest & Legal Research System)
  - **Pomodoro Web App** (Productivity & Focus Timer)
- **Interactive Tech Stack Matrix**: Categorized system runtime, database, language, and client-side architecture cards with interactive animated filtering tags.
- **Full Viewport Responsiveness**: Fluid layout scaling from mobile viewports (375px) up to 4K displays.

## 💻 Getting Started

### Prerequisites

- Node.js 18.17+ or 20+ installed.

### Installation

```bash
# Clone the repository
git clone https://github.com/alexius-seth/web-portfolio.git

# Navigate into the project directory
cd web-portfolio

# Install dependencies
npm install
```

### Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

### Production Build

```bash
npm run build
npm run start
```
